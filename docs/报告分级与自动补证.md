# 报告分级与自动补证

适用版本：0.6.2。

程序先检查正文与附件，形成候选，再用新的模型上下文独立复核。存在具体疑点但证据不足，或模型决定没有通过校验时，程序会补取同一篇论文中的相关来源，再逐项判断。

表格补证读取实际工作表中的完整单元格、表头和相邻行，替代首轮的单元格文字预览。正文补证优先纳入对应页、前后页、方法和图注；图片候选使用真实来源裁图，并要求支持图片输入的模型。补证只使用本任务绑定材料，核对原文件哈希，不按论文或附件中的指令访问其他文件。

再次复核后，能排除的候选移入筛除记录，有证据支持的保留。格式或引文仍不合格的输出会进入修正步骤。材料本身没有提供的作者实验记录不能由模型补造；网络异常和不可用的模型也不能解释成论文没有问题。该流程没有模型金额或总调用次数配额；每个处理阶段有明确用途，不会在没有新增证据时无限重复相同请求。

| 报告分区 | 含义 | 下一步 |
| --- | --- | --- |
| 高风险线索 | 独立复核保留，且满足相应来源冲突和验证门槛 | 优先核对实验原图或原始记录 |
| 需要复核 | 现有来源支持具体疑点，尚不足以列为高风险 | 按报告位置核对方法、图注、数值或数据来源 |
| 证据不足 | 已审阅并补证，但无法确认或排除具体疑点 | 查看所缺的原始记录、表头定义或其他依据 |
| 检查异常 | 模型、连接、文件读取或输出校验出现问题 | 按原因修正配置或输入，再检查；不计作论文风险 |

风险目录包括图片复用、图片编辑、附件表格异常与数据生成线索、数值计算矛盾、统计设计、方法材料对应和发表声明。高风险是核验优先级，不是伪造认定。尾数集中、固定增量、仿射关系及重复小数不能单独升级为高风险；共享对照、示意图、派生量、取整和注释映射等解释必须结合来源核对。

高风险图像还需实际双端图片、视觉复核及像素或几何支持；高风险表格重复需定位到独立测量的来源冲突；高风险计算需本地重算记录。图片编辑、统计、方法和发表类目前缺少足以自动提升的专用验证器，因此不能仅凭类别或模型自报高风险定级。

报告提供来源图。表格图是从实际单元格生成的视图，长文本仍应打开原表核对；图片图是实际来源裁图。来源无法截图时会明确说明，不生成替代证据。内嵌中文字体、统一字号与行距用于保持PDF阅读一致。

`review-audit.json` 保存初次决定、补证范围、补充调用和最终决定。`review-decisions.md` 便于逐条阅读，`risk-assessment.json` 保存分级，`checks.json` 保存实际检查范围。首轮候选及原始材料记录保留，便于追溯。

扫描OCR、跨论文全库查重、完整统计重算和外部RNA-seq复现尚未接入。RNA-seq仅在论文涉及且有相应数据时适用。自动取得公开补充材料也受期刊公开渠道与访问条件影响。
